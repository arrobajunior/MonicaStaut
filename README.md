# Monica Staut — site institucional

Site estático, responsivo e sem dependências de build para o domínio `monicastaut.com`.

## Estrutura

- `index.html` — conteúdo, SEO e navegação.
- `styles.css` — layout responsivo, tipografia, animações sutis, contraste e preferências de movimento reduzido.
- `script.js` — navegação mobile, barra de leitura, indicação da seção ativa e entrada suave no scroll.
- `assets/` — fotos autorizadas fornecidas para o projeto e logos recortadas das referências enviadas.
- `CNAME` — domínio personalizado, para publicação via GitHub Pages.

## Abrir localmente

Abra `index.html` em um navegador ou utilize um servidor HTTP local, por exemplo `python -m http.server 8000`.

## Publicar no GitHub Pages

1. No repositório GitHub: Settings > Pages.
2. Em **Build and deployment**, selecione **Deploy from a branch**, `main` e `/ (root)`.
3. Configure os registros DNS do domínio `monicastaut.com` no provedor e ative HTTPS após a propagação.
4. Verifique se o e-mail `contato@monicastaut.com` está ativo; os botões de palestras e contato abrem o aplicativo de e-mail do visitante.

**Importante**: apenas enviar o código não altera DNS nem ativa automaticamente o GitHub Pages.

## Identidade

A página pessoal usa vinho/off-white, enquanto as seções CASA e KINDVIA usam suas cores próprias. Os mockups de telas e dispositivos são ilustrações em HTML/CSS, não capturas reais do produto. Fotografias vieram de arquivos fornecidos pelo usuário.
